# BankSphere — Banking Management System

A full-stack banking management application built using Java, Spring Boot, React.js, and MySQL.

## Overview
BankSphere is a web-based application designed to manage customers, bank accounts, and financial transactions.

## Technologies Used
- Java
- Spring Boot
- React.js
- JavaScript
- HTML and CSS
- MySQL
- REST APIs
- Git and GitHub
- Postman

## Features
- Customer management
- Bank account management
- Deposit and withdrawal operations
- Transaction history
- Database integration using MySQL

## Project Structure
- `banking-api/` — Backend application
- `banking-frontend/` — Frontend application
